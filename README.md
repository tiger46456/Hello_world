## 5th Grade Math Worksheet

This repository also includes a printable 5th grade math worksheet (`math_worksheet.html`) that is optimized for A4 paper (210mm x 297mm).

### Features:
- Semantic HTML structure
- Various 5th grade appropriate math problems:
  - Addition and Subtraction
  - Multiplication and Division
  - Fractions
  - Decimals
  - Word Problems
- Professional CSS styling for readability
- Print-optimized layout with `@media print` rules
- Student information section (name, date, score)
- Clear problem numbering and answer spaces
- Proper page breaks and margins for printing

### Usage:
1. Open `math_worksheet.html` in a web browser
2. Press Ctrl+P (Windows/Linux) or Cmd+P (Mac) to print
3. Or click the "Print Worksheet" button on the screen

The worksheet is designed to print perfectly on A4 paper with proper margins and formatting.
