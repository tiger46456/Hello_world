# 5th Grade Math Worksheets

This project contains 10 printable math worksheets designed for 5th grade students, optimized for A4 paper (210mm x 297mm).

## Features

- **10 unique worksheets** covering various 5th grade math topics
- **Print-optimized CSS** with `@media print` for proper A4 formatting
- **Professional layout** with space for student name, date, and scores
- **Diverse problem types**: multiplication, division, addition, subtraction, fractions, decimals, word problems, geometry, and measurement
- **Responsive design** that looks great on screen and prints perfectly
- **Easy navigation** with an index page linking to all worksheets

## Worksheets Included

## How to Use

1. Open `index.html` in a web browser to see all available worksheets
2. Click on any worksheet to view it
3. Use your browser's Print function (Ctrl+P or Cmd+P) to print
4. Ensure A4 paper size is selected in your print settings
5. Print directly or save as PDF for later use

## Technical Details

- All worksheets use semantic HTML5 markup
- CSS Grid layout for responsive problem arrangement
- Print-specific CSS ensures proper formatting on A4 paper
- Page break rules prevent problems from splitting across pages
- Screen-only elements are hidden when printing
- Consistent styling across all worksheets via shared CSS file
